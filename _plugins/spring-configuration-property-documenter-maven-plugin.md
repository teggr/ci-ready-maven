The Spring Configuration Property Documenter Maven Plugin turns the `spring-configuration-metadata.json` generated by Spring Boot into human-readable configuration reference documentation. It can emit Markdown, AsciiDoc, HTML, or XML, which helps teams publish accurate property docs as part of their normal Maven build instead of manually maintaining README tables. In CI, that keeps configuration documentation close to the code, makes changes to application properties visible in pull requests, and supports aggregating docs across multi-module builds when needed.

## Code Example

```xml
<plugin>
    <groupId>org.rodnansol</groupId>
    <artifactId>spring-configuration-property-documenter-maven-plugin</artifactId>
    <version>0.7.2</version>
    <executions>
        <execution>
            <id>generate-property-docs</id>
            <phase>verify</phase>
            <goals>
                <goal>generate-property-document</goal>
            </goals>
            <configuration>
                <type>MARKDOWN</type>
            </configuration>
        </execution>
    </executions>
</plugin>
```
